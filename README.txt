ÉLECTROF3 — STRUCTURE DE BASE

Fichiers :
- index.html : page d'accueil
- seconde.html : espace Seconde F3
- premiere.html : espace Première F3
- terminale.html : espace Terminale F3
- style.css : mise en page adaptée aux téléphones
- app.js : enregistrement du service worker
- manifest.json : paramètres de l'application installable
- service-worker.js : mise en cache pour les pages hors connexion

PUBLICATION SIMPLE DEPUIS ANDROID
1. Décompresse ce ZIP dans le gestionnaire de fichiers.
2. Sur GitHub, crée un dépôt public nommé electrof3.
3. Téléverse tous les fichiers de ce dossier à la racine du dépôt (pas le ZIP lui-même).
4. Ouvre Settings > Pages.
5. Dans la partie publication, choisis Deploy from a branch, branche main, dossier /(root), puis Save.
6. Attends que GitHub Pages affiche l'adresse du site. Ouvre cette adresse en HTTPS dans Chrome.
7. Dans Chrome Android, menu ⋮ > Installer l'application ou Ajouter à l'écran d'accueil.
8. Ouvre une première fois les pages avec internet. Les pages enregistrées seront ensuite mises en cache pour un usage hors connexion.

Important : cette structure est un point de départ, pas encore une application scolaire complète. Les contenus pédagogiques doivent être développés et vérifiés selon le programme officiel et les cours de l'établissement. Les pages hors ligne fonctionnent lorsque le site est servi en HTTPS et que la mise en cache s'est achevée.
